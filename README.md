# HR 数据智能标准化与分析平台 · 可运行 Demo

在「区域原始数据」与「总部标准 Output」之间增加一层**数据标准化层**的可运行演示。

核心设计判断：**AI 只负责「理解」，代码负责「执行」**。AI 输出结构化的字段映射建议，
解析 / 清洗 / 校验 / 指标计算 / 图表全部由确定性代码完成，AI 不直接修改任何原始数据。

> ⚠️ 本演示中**全部数据均为程序生成的虚构数据**，不含任何真实姓名、账号、薪资或个人信息。
> 姓名一律脱敏展示。

## 本地运行

本仓库根目录的 `index.html` 是**自包含单文件版**（内联全部 JS / CSS，零外部请求）：
直接下载双击即可打开，无需安装任何依赖，断网也能运行。

如需从源码运行：

```bash
npm install
npm run dev        # http://127.0.0.1:5173/
npm run build      # 生产构建
npm run verify     # 回归验证（数据 / 映射 / 口径 / 渲染）
```

## 演示的完整闭环

```
上传区域原始数据
  → AI 字段语义识别（字段名 + 脱敏样本双通道）
  → 低置信度字段进入人工确认
  → 人工释义：确认 / 修正 / 备注 / 指定单位换算
  → 确定性代码执行标准化转换
  → 数据质量校验与评分
  → 标准数据层
  → 分层 Output（总部看区域 · 区域看门店 · 门店看员工）
  → 人工确认结果沉淀进知识库，下次自动复用
```

## 三个关键机制

**1. 置信度分级，AI 不假装确定**
`≥86%` 自动通过 · `50%–86%` 进入人工确认 · `<50%` 判为区域自建字段（无需映射）。
低置信度字段不会被静默处理。

**2. 每一行都可人工释义，而不只是低置信度字段**
已匹配、已确认、无需映射的行同样可以复核：确认 AI 判断无误 / 修正映射 / 判为无需映射。
支持写入**人工备注**（口径解释）与指定**结构化单位换算**（如「年 → 月 ×12」）。

典型场景：底表有一列「入职时长」，语义是司龄，但原始值形如 `6Y` / `7M`，
而标准字段是「司龄(月)」——单位不一致，不能直接确认映射。
人工写下备注并指定换算规则后，由代码执行 `6Y → 72`。
**未确认换算规则时，`6Y` 会被解析为 `null` 而不是静默变成 `6`**，避免脏数据流入分析层。

**3. 三层知识库，把人工成本变成可复用资产**
- **L1** 总部标准字段（固定，区域不可修改）
- **L2** 全国通用同义词
- **L3** 区域特殊映射（人工确认后沉淀）

L3 沉淀的不只是映射关系，而是三类资产：正向映射、单位换算规则、**排除型知识**
（人工确认「无需映射」的字段）。排除型知识同样会被下次命中复用，否则人工每次都要重做。

## 技术栈

React 18 · TypeScript · Vite 5 · Tailwind CSS 3 · Recharts 2 · SheetJS

纯前端：Mock 数据 + 浏览器内本地处理，**无后端 / 数据库 / Docker / 消息队列**。
AI 采用 Provider 抽象层，默认内置 Mock Provider；接入真实 AI 服务只需配置环境变量，
且失败时自动降级，不中断演示。
